# SECURITY
This tool is defensive only. It does not execute attacker commands. All outputs are simulated, credentials are fake, and files are fake.

- External binding is disabled by default (`127.0.0.1`).
- Cloud AI is disabled by design.
- Internet access is not required after install.
- Use isolated lab VLANs and host firewall rules to restrict inbound access.

## Reporting security issues
Open a private issue with reproduction details and expected safe behavior.
